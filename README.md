# Bookmarklets

How to install and use bookmarklets

1. Show your Bookmarks Bar in your browser (Ctrl+Shift+B on Windows or Cmd+Shift+B on Mac).
2. Right-click on the bookmarks bar and select Add Page or New Bookmark.
3. Name it something descriptive like "🎯 Focus Mode".
4. Paste the javascript code above into the URL or Location field.
5. Save it.

Now, go to any webpage, click your new bookmarklet to activate it, and start pressing Tab to see it in action. Clicking the bookmarklet a second time will deactivate it and return the page to normal.
